# Projetos profissionais selecionados

Este repositório reúne estudos de caso resumidos de projetos profissionais e internos em que participei.

Por questões de propriedade intelectual, confidencialidade e segurança, os códigos-fonte, credenciais, dados de clientes, configurações internas e determinados detalhes de implementação não são disponibilizados publicamente.

O objetivo é apresentar o contexto técnico, os problemas solucionados, as tecnologias utilizadas e minha participação em cada projeto.

---

## Projetos

### Automação de ofertas e distribuição multicanal

Sistema para captura, processamento e distribuição automática de ofertas provenientes de marketplaces.

**Integrações**

- Amazon;
- Mercado Livre;
- Shopee;
- WhatsApp;
- Telegram;
- Instagram;
- n8n.

**Principais responsabilidades**

- integração com APIs de marketplaces;
- processamento e normalização de ofertas;
- automação dos fluxos com n8n;
- distribuição das ofertas entre diferentes canais;
- integração com mensageria e redes sociais.

---

### ERP para pequenos comércios

Sistema voltado à gestão operacional de pequenos estabelecimentos, integrado ao ecossistema do GestãoClick.

**Principais áreas**

- integração com API REST;
- sincronização de informações comerciais;
- produtos;
- vendas;
- clientes;
- automação de processos administrativos.

---

### Site institucional da Arkea

Desenvolvimento e evolução do site institucional da Arkea Soluções Inteligentes .

O projeto envolveu implementação frontend, responsividade, organização de conteúdo e identidade digital da empresa.

---

### Plataforma interna de integração com WhatsApp

Desenvolvimento de soluções internas para integração de sistemas com o WhatsApp.

Foram exploradas duas abordagens distintas:

**Integração baseada em WhatsApp Web**

- utilização da biblioteca Baileys;
- gerenciamento de sessões;
- envio e recebimento de mensagens;
- processamento de mídias;
- acompanhamento de status;
- automações internas.

**Integração oficial**

- WhatsApp Business Platform;
- API oficial da Meta;
- webhooks;
- envio e recebimento de mensagens;
- tratamento de eventos e status.

---

### Sistema de independência financeira

Aplicação voltada ao acompanhamento financeiro e à projeção de independência financeira.

O projeto envolve organização de dados financeiros, importação e tratamento de transações, simulações e visualização de informações para apoio ao planejamento financeiro.

## Por que o código não está disponível?

Parte dos projetos apresentados neste repositório foi desenvolvida em contexto profissional ou empresarial.

Por esse motivo, este repositório não contém:

- código-fonte proprietário;
- credenciais ou tokens;
- configurações de infraestrutura;
- dados de clientes;
- regras comerciais sensíveis;
- documentação interna;
- informações protegidas por contratos ou acordos de confidencialidade.

As descrições foram deliberadamente limitadas a informações que podem ser apresentadas como parte do meu portfólio profissional.

## Objetivo

O objetivo deste repositório é complementar meus projetos públicos.

Enquanto outros repositórios permitem a inspeção direta do código, estes breves estudos de caso demonstram experiência adquirida em projetos reais cuja implementação completa não pode ser disponibilizada publicamente.
